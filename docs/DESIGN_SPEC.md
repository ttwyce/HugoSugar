# HugoSugar — UI 设计规范（v1）

> 关键词：**简洁、克制、正文优先**。
> 参考气质：纯纯写作 / iA Writer —— 界面退到背后，文字站到前面。
> 「简洁」不是元素少，而是**每个界面只有一个视觉焦点**。

---

## 一、设计原则（四条，冲突时按序取舍）

1. **正文优先**：编辑器里除了文字，不出现任何常驻干扰。工具栏悬浮、可隐藏。
2. **少即是多**：一个界面只留 1 个主操作（FAB 或底部按钮），次要用「更多」收纳。
3. **层级靠留白，不靠框线**：优先用间距分组，其次用分割线，最后才用卡片/阴影。
4. **动效克制**：只做 150~200ms 的位移与透明度过渡，不做花哨弹跳。

## 二、双主题

跟随系统，可手动锁定亮/暗。**两套都是完整设计，不是暗色靠反色硬生成。**

### 2.1 色彩 Token

| Token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `background` | `#FFFFFF` | `#121212` | 页面底色 |
| `surface` | `#F7F7F8` | `#1A1A1C` | 卡片 / 输入框底 |
| `surfaceHigh` | `#EFEFF2` | `#242427` | 悬浮层 / 选中态 |
| `textPrimary` | `#1A1A1A` | `#E8E8EA` | 正文标题 |
| `textSecondary` | `#6B6B70` | `#9A9AA0` | 时间、摘要、说明 |
| `textTertiary` | `#A0A0A6` | `#6B6B72` | 占位符、禁用 |
| `divider` | `#EAEAEC` | `#2A2A2E` | 分割线 |
| `accent` | `#3A6B5C` | `#7FBFA8` | 主色（墨绿，安静不喧闹） |
| `accentSoft` | `#EAF2EF` | `#1E2A26` | 主色浅底（标签、选中） |
| `danger` | `#C4443C` | `#E5736B` | 删除、错误 |
| `warning` | `#B07C21` | `#D9A84E` | 未保存、冲突 |

> **为什么主色是墨绿**：写作 App 的主色出现频次极低（只有按钮和选中态），但饱和的蓝/紫会抢注意力。墨绿沉稳、与纸感契合，且不撞 Hugo 的品牌黑。
> 也可用 Material You 动态取色，但**默认关闭**——动态色会破坏「安静」这个核心气质。

### 2.2 字体与排版

| 场景 | 字号 | 行高 | 字重 | 字间距 |
|---|---|---|---|---|
| 列表标题 | 16 | 1.4 | 500 | 0 |
| 列表摘要 | 13 | 1.5 | 400 | 0 |
| **编辑正文** | **17** | **1.75** | 400 | 0.2 |
| 编辑器标题行 | 22 | 1.4 | 600 | 0 |
| 预览正文 | 16.5 | 1.8 | 400 | 0.2 |
| 按钮 | 15 | 1.2 | 500 | 0.3 |
| 说明文字 | 12 | 1.4 | 400 | 0 |

- **行高 1.75 是重点**。中文长文阅读，1.5 会挤，1.8 会散，1.75 最舒服。
- 正文字体默认跟随系统（`-apple-system` / `Roboto` / `思源黑体`）。
- **提供一个「衬线体」开关**（设置里），开启后用 `NotoSerifSC` / `Songti SC`，适合正式文章。
- **全角标点、中英混排**：中文与英文/数字之间自动留 1/8 空格（编辑器层做，不在 UI 层）。

### 2.3 圆角与间距

```
radius:  sm=8   md=12   lg=16   pill=999
space:   4 / 8 / 12 / 16 / 20 / 24 / 32
```

- 卡片用 `md`（12），按钮用 `pill` 或 `md`，底部面板用 `lg`（顶部两角）。
- 页面左右边距：**列表 16，编辑器 20**（编辑区要更松一点）。

### 2.4 阴影

**几乎不用**。只两处：
- FAB / 悬浮工具条：`BoxShadow(blur 16, y 4, black 8%)`
- 底部弹出面板：`BoxShadow(blur 24, y -4, black 10%)`

其余一律靠底色差异分层。

## 三、页面结构

### 3.1 五个 Tab

```
┌─────────────────────────┐
│  文章                    │  ← 顶部只有标题，无 AppBar 阴影
│                         │
│  ● 未发布 2              │  ← 可选：草稿提示条
│                         │
│  文章标题                │
│  摘要 · 3 天前           │
│  ───────────────────    │
│  文章标题                │
│  摘要 · 上周             │
│                         │
│                    (+ ) │  ← FAB 唯一主操作
├─────────────────────────┤
│ 文章  笔记   AI   站点  设置│
└─────────────────────────┘
```

- **Tab 只有文字或极简图标**，不做选中填充块，选中态用主色文字 + 顶部 2px 短线（iOS 风格）。
- **文章列表分组**：默认按「最近修改」平铺；可切「草稿 / 已发布 / 单页」。

### 3.2 编辑器（核心页面，必须最干净）

```
← 返回         ···  ← 悬浮，输入时淡出
─────────────────────
标题                    ← 22sp，无边框输入框
tags · draft
─────────────────────
正文开始……




                          [悬浮：预览 | AI]
```

- **进入即全屏**，无 Tab 栏。
- **顶栏自动淡出**：滚动或输入 2 秒后，顶栏透明度降到 0.15，点任意处恢复。这是「纯纯写作」最舒服的一点。
  - 实现补充（M2 实测修正）：「点任意处恢复」必须同时**取消淡出计时器**，否则点一下亮起、2 秒后又暗，等于点了没用。
  - 点击捕获用 `Listener.onPointerDown`，不能用 `GestureDetector.onTap` —— 后者会被正文 `TextField` 抢走。
  - 改标题与改正文同等对待，都要重置计时器。
- **底部区域不参与淡出**：Markdown 工具栏 + 状态行是操作入口，常驻显示。淡出只作用于顶栏。
- **状态栏极简**：只显示字数 / 保存状态，居中或右下角小字。
- **Markdown 工具栏**：底部常驻单行、横向可滚，左侧固定撤销 / 重做。
  - 包裹型（粗体 / 斜体 / 删除线 / 行内代码）：有选中就包住选区，无选中插入占位并选中占位。
  - 行前缀型（H1-H3 / 引用 / 列表）：作用于光标所在整行，再点一次取消。
  - 撤销栈 450ms 内合并为一步，标题与正文同栈回退，避免错位。
- **预览**：从底部滑出，占 70% 高度，可上下拖。

### 3.3 笔记

与文章列表同构，但：
- 卡片式（`surface` 底 + `md` 圆角 + 12 padding），因为笔记短、碎片化，卡片更易扫读。
- **置顶区**独立，顶部一条 `置顶 · N`，视觉上轻微区隔（`surfaceHigh` 底）。
- 置顶的笔记在行尾有一个小圆点标记 —— 因为它会进 AI 的上下文，值得被看见。

### 3.4 AI 对话

- **不只是聊天气泡**。工具调用折叠成一行灰色小条：`▸ 读了「写作偏好」`，点击展开。
- `write_post` 的 Diff：**行内红绿高亮**，底部两个按钮「拒绝 / 应用」。
- **输入框固定底部**，但上方留 1 行提示区，显示当前会话注入了哪些置顶笔记（让用户知道 AI 看到了什么）。

### 3.5 设置

标准 iOS 风格分组列表，`surface` 底、`divider` 分隔、无卡片阴影。

分组：
1. 外观（主题模式 / 正文字体 / 字号）
2. 站点（当前站点 / 远程仓库 / Vercel Hook）
3. AI（API 配置 / System Prompt）
4. 关于

## 四、组件规格

| 组件 | 规格 |
|---|---|
| 列表项 | 高 64（双行）/ 48（单行），左边距 16，分割线缩进 16 |
| FAB | 56×56，`accent` 底，白色图标，右下 16 |
| 底部导航 | 高 56 + 安全区，背景 `background` + 顶部 1px `divider`，**无阴影** |
| 标签 Chip | 高 24，`accentSoft` 底，`accent` 字，`pill` 圆角，padding 8×2 |
| 输入框 | `surface` 底，`md` 圆角，无边框，内边距 12 |
| 主按钮 | 高 48，`accent` 底，白字，`md` 圆角，全宽 |
| 次按钮 | 高 48，透明底，`accent` 边框 1px |
| 空状态 | 居中，图标 48（`textTertiary`）+ 一行说明 14（`textSecondary`），无插画 |

## 五、动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 页面切换 | 250ms | `easeOutCubic` |
| 底部面板 | 280ms | `easeOutCubic` |
| 顶栏淡出 | 200ms | `easeInOut` |
| 按钮按下 | 100ms | 透明度 1→0.7 |
| Diff 展开 | 200ms | `easeOut` |

**禁止**：弹跳、缩放超过 1.05、超过 400ms 的动画。

## 六、实现约定

```dart
// lib/app/theme/
├─ app_theme.dart       // ThemeData buildLight() / buildDark()
├─ app_colors.dart      // ColorScheme + 自定义 token 扩展
└─ app_typography.dart  // TextTheme + 编辑器专用 TextStyle
```

**规则**：

1. **禁止在 Widget 里写 `Color(0xFF...)`**。一律从 `Theme.of(context)` 或自定义 `ThemeExtension` 取。
2. 自定义 token（`textTertiary`、`accentSoft` 等）用 `ThemeExtension<AppColors>` 实现，亮暗各一套。
3. 编辑器字号/行高/字体作为「阅读偏好」存入设置，**不写死**。
4. 任何界面在亮暗两主题下都要截图检查一遍——**暗色不是反色**，`surface` 与 `background` 的差值要够（否则分层消失）。
