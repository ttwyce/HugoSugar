# 本次改动方案（第一轮）

## 已确认的现状

- 项目里**没有任何 AI 后端**：无 provider、无 API key 字段、无 LLM 请求代码，
  `lib/features/ai/chat_page.dart` 整页是硬编码假数据。
- 文章删除是**硬删除**（`SiteController.deletePost` 直接 `storage.delete`），没有回收站。
- 笔记已有回收站（`deletedAt` 字段 + `NoteView.trashed`）。
- 笔记列表是单列 `ListView`，卡片固定宽度自适应。

## 本轮要做的

1. **Tab 互换**：想法(原笔记)成为第 1 个 Tab，文章成为第 2 个。
2. **笔记改名「想法」**：UI 文案全部改，代码标识符保持 `Note` 不动
   （内部名不影响用户，重命名会造成大范围无收益改动）。
3. **想法列表改两列瀑布流**。
4. **文章回收站**：软删除 + 回收站视图 + 恢复 + 永久删除。
5. **AI 上下文规则**：废除「只有置顶才进 AI」，改为默认全部想法，
   支持按分组选择。这一步先落到可测的纯逻辑层。

## 本轮不做的

- AI 历史记录 / 回滚 / token 统计 / 上下文压缩 / 网络搜索 / 读文档
  —— 这些**依赖真实 LLM 调用**，没有后端就是造假 UI，不做。

## 违反项确认

用户说「token 统计、上下文压缩、历史记录、回滚」等 AI 基本操作，
当前项目连一次 LLM 请求都发不出去。这些功能必须在接入模型之后才有意义。
